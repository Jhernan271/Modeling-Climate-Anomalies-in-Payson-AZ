# Modeling-Climate-Anomalies-in-Payson-AZ
-Statistical climate analysis of Payson, AZ using NOAA climate data and USGS groundwater level data using machine learning packages. 

-This project explores minimum and maximum temperature, precipitation, and groundwater levels(GWLs).

-Data sources include the Payson NOOA station USW00093139 tracked for daily tmax, tmin, and prcp and USGS well USGS-341408111212001 returning daily GWL means for this well located approximately .5 mile apart obtained using NOAA and USGS API access. 

-The datasets are merged and graphed to investigate climate trends and predictors in the Tonto National Forest region of Payson, AZ located in the Mogollon Rim.

-Machine Learning/Data Science pacakges used: Pandas, Numpy, Matplotlib, Seaborn
